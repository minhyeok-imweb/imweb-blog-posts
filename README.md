# imweb-blog-posts

아임웹 채용 블로그(team.imweb.me)의 **공개 글 목록**을 모아 `posts.json` 으로 유지하는 저장소입니다.
채용 공고 하단 카드 코드(`[[cards: ...]]`)를 만드는 사내 도구가 이 파일을 읽어갑니다.

- 담긴 정보: 공개 블로그 글의 제목 / 주소 / 썸네일 주소 / 분류 / 날짜 — 전부 로그인 없이 볼 수 있는 내용입니다.
- 자격증명·개인정보는 들어가지 않습니다.
- `.github/workflows/update-posts.yml` 이 **하루 3번(09/15/21시 KST)** 자동으로 다시 수집합니다.
  Actions 탭에서 수동 실행도 가능합니다.

수동으로 돌리려면:

```bash
python3 scrape.py
```

블로그 HTML 구조가 바뀌어 수집이 5건 미만이 되면 기존 파일을 덮어쓰지 않고 실패 처리합니다.
게시판이 늘어나면 `scrape.py` 의 `BOARDS` 에 한 줄만 추가하면 됩니다.
